# 云边一体化工作台交付说明

## 首次使用（Windows）

1. 安装 Python 3.11 或 3.12，勾选 **Add Python to PATH**（最低支持 3.10）。
2. 将 ZIP 完整解压到可写目录，例如 `E:\云边一体化工作台`，不要直接在压缩包内运行。
3. 双击 `安装依赖.bat`，等待“安装完成”。此步骤需要联网下载 requirements.txt 中的依赖。
4. 双击 `启动工作台.bat`，在浏览器打开 http://127.0.0.1:18768/ 。
5. 用 `停止工作台.bat` 停止服务。代码升级后重启服务并刷新页面。

端口被占用时使用 `powershell -ExecutionPolicy Bypass -File .\start.ps1 -Port 18769`，再打开对应端口。

## 包内内容与数据

本版包含查询失败后继续生成、示例格式的资产/设备/关系 CSV、历史记录统一 ZIP 下载，以及更明确的预检和任务失败提示。缺失 MQTT 凭据按设备名生成，真实查询所得凭据保留；使用模板凭据时须先导入平台并核对。

- 包含后端源码、网页及图标、必要 XML/CSV 模板、平台规则链模板、回归测试、启动/停止/安装脚本。
- 不包含本机 data、账号密码、网关生成包、测试截图、模板历史备份或虚拟环境。
- 第一次运行自动创建 data 目录。接收方需要自行配置平台和网关，创建或绑定自己的设备池。
- 虚拟环境不能跨电脑或操作系统复制。Windows DPAPI 凭据绑定原 Windows 用户，复制 data 不等于完成数据迁移。
- 交付 ZIP 是源码安装包，不是无需 Python 的离线独立程序。

## 检查与使用边界

Windows 执行 `.\.venv\Scripts\python.exe -m unittest discover -s tests -v`。
其他系统可执行 `python tests/run_portable.py`，仅验证离线业务逻辑，内存凭据替代不代表 DPAPI 验证通过。

本次交付的具体检查结果见包内 `交付检查结果.txt`；`SHA256SUMS.txt` 提供文件校验清单。真实平台、网关和 Windows DPAPI 仍需在目标环境验收。

压测流程、设备复用、只读遥测核验和验收指标详见 README.md；贡献规则见 AGENTS.md。
